# 模型多段发送

入口：设置 → 个性化 → 模型多段发送。默认关闭；分段发送间隔默认 200 毫秒，支持滑块或数字输入 0～10000 毫秒，0 表示立即全部显示。

## 输出协议

开启后，在角色提示词和长期记忆之后附加本次回复的 JSON 输出要求。继续使用现有接口，不强制传入服务商特有的 response_format 参数。

```json
{"messages":[{"text":"早。"},{"text":"你今天起得好早。"}]}
```

- 按 messages 数组顺序显示各个 text。自然分成 1～6 段；超出 6 段时合并尾部，保留全部文本。
- 传输仍支持流式接收，但结构化正文先缓冲，完整收到并校验后才显示，避免泄露半截 JSON。思考过程仍独立处理。
- 可以去掉完整的 Markdown JSON 围栏；普通文本降级为单段。损坏、空或字段类型错误的 JSON 提示格式错误，允许手动重试，不自动发起额外请求。
- 先解析 JSON 转义，再清理 text 中的动作标签；一次回复只执行第一个有效动作。
- 取消或网络失败不保存半截结构化回复。关闭开关后继续使用原有普通文本流式回复。

## 存储与整组操作

一次回复只保存一个 ChatMessage/分支节点：segments 保存气泡正文，content 保存以换行连接的完整正文，reasoning 独立保存。历史结构版本升级至 4，旧记录没有 segments 时显示成一条消息。

上下文、搜索、记忆和消息计数仍按逻辑消息处理。朗读与自动 TTS 都将完整正文一次送往语音模型；自动朗读在整组显示完毕后启动。重新生成和版本切换替换整个回复组，支持不同段数的版本。长按任意一段操作同一个消息节点。

## Line 排版

首段显示头像、名称和与气泡连续的短尾巴；后续气泡对齐首段正文边缘，不重复显示头像、名称或尾巴。同组气泡间距 5 dp。末段旁显示时间（角色在右，我方在左），末段下方显示整组朗读、重试和版本控制。自定义气泡颜色也应用于尾巴。

新回复依次出现并淡入展开；读取历史或切换版本立即显示完整组。若在展示中继续发送、重新生成或切换版本，停止旧组展示任务并显示其已保存的完整内容，避免旧组音频随后播放。

普通聊天、Line Mode 和 Live2D 聊天使用同一渲染组件；桌面壁纸文字气泡按相同间隔追加各段，整组保存并只合成一次语音。

## 验证

单元测试覆盖分块接收、JSON 转义、动作标签、普通文本与代码围栏降级、无效格式、取消、不丢失尾部文字，以及整组版本的保存、恢复和上下文序列化。界面的实机视觉效果需安装 APK 后复核。
