# Live2D 模型下载源

本文记录当前代码实际使用的模型来源。这里的“模型”指角色的 Live2D 文件，不是聊天所用的 LLM 模型。

## 在线下载

应用内“下载模型”和“更新模型”共用一个地址模板：

```text
https://modelscope.cn/datasets/HELPMEEADICE/BanG-Dream-Live2D/resolve/master/models/<角色 ID>.zst
```

- 平台：ModelScope（魔搭社区）
- 数据集：[`HELPMEEADICE/BanG-Dream-Live2D`](https://modelscope.cn/datasets/HELPMEEADICE/BanG-Dream-Live2D)
- 分支及目录：`master/models/`
- 文件格式：每个角色一个 `.zst` 压缩模型包。`<角色 ID>` 来自应用角色数据，拼接 URL 前会进行 UTF-8 URL 编码。例如 `anon` 对应 [`anon.zst`](https://modelscope.cn/datasets/HELPMEEADICE/BanG-Dream-Live2D/resolve/master/models/anon.zst)。

下载地址写在 [`ZstModelArchive.downloadUrl()`](../app/src/main/java/com/bangdream/pet/data/ZstModelArchive.kt)；模型页通过同一类的 `downloadCharacter()` 执行下载或更新。当前代码只配置了这一个在线地址，没有镜像或自动回退源。下载时允许 HTTP 重定向，成功后把文件保存到应用内部目录 `files/models/<角色 ID>.zst`。读取模型时，已下载文件优先于 APK 内置资源。

## APK 内置模型

部分角色模型随 APK 打包，来源于 Git 子模块 [`panxuc/live2d-widget-mygo`](https://github.com/panxuc/live2d-widget-mygo) 的 `public/model/`，子模块地址记录在 [`.gitmodules`](../.gitmodules) 中。构建任务 [`syncLive2DAssets`](../app/build.gradle.kts) 将其复制到应用 assets 的 `models/` 下。

| 角色 ID | 角色 |
| --- | --- |
| `anon` | 千早爱音 |
| `rana` | 要乐奈 |
| `soyo` | 长崎素世 |
| `taki` | 椎名立希 |
| `tomori` | 高松灯 |

这些目录可离线读取，不经过上述 ModelScope 下载接口。克隆项目时使用 `git clone --recurse-submodules`，或在已有仓库中执行 `git submodule update --init --recursive`，以获取内置资源。

## 素材来源与说明

内置模型的 [上游 README](https://github.com/panxuc/live2d-widget-mygo#介绍) 说明，其模型来自 Bestdori 提供的 BanG Dream! 游戏数据包，并为适配生成了 `index.json` 等文件。上游注明仅供学习交流、请勿商用。角色素材版权归各自权利人所有，代码许可不授予额外素材授权。

ModelScope 地址是**应用配置的下载托管地址**，不等同于素材的原始版权来源。本文依据当前代码记录下载配置，不保证每个角色包持续可用；在线数据集包内容也不保证与内置子模块完全一致。
