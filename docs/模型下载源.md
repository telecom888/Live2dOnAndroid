# Live2D 模型下载源

本文记录当前代码实际使用的模型来源。这里的“模型”指角色的 Live2D 文件，不是聊天所用的 LLM 模型。

## 在线下载

应用内“下载模型”和“更新模型”共用一个地址模板：

```text
https://modelscope.cn/datasets/HELPMEEADICE/BanG-Dream-Live2D/resolve/master/models/<角色 ID>.zst
```

- 平台：ModelScope（魔搭社区）
- 数据集：[`HELPMEEADICE/BanG-Dream-Live2D`](https://modelscope.cn/datasets/HELPMEEADICE/BanG-Dream-Live2D)
- 分支及目录：`master/models/`
- 文件格式：每个角色一个 `.zst` 压缩模型包。`<角色 ID>` 来自应用角色数据，拼接 URL 前会进行 UTF-8 URL 编码。例如 `anon` 对应 [`anon.zst`](https://modelscope.cn/datasets/HELPMEEADICE/BanG-Dream-Live2D/resolve/master/models/anon.zst)。

下载地址写在 [`ZstModelArchive.downloadUrl()`](../app/src/main/java/com/bangdream/pet/data/ZstModelArchive.kt)；模型页通过同一类的 `downloadCharacter()` 执行下载或更新。当前代码只配置了这一个在线地址，没有镜像或自动回退源。下载时允许 HTTP 重定向，成功后把文件保存到应用内部目录 `files/models/<角色 ID>.zst`。读取模型时，已下载文件优先于 APK 内置资源。

## APK 内置模型

部分角色模型随 APK 打包，来源于仓库的 `live2d-widget-mygo/public/model/`，构建任务 [`syncLive2DAssets`](../app/build.gradle.kts) 将其复制到应用 assets 的 `models/` 下。当前仓库内可见的角色目录为 `anon`、`rana`、`soyo`、`taki`、`tomori`。这些目录可离线读取，不经过上述 ModelScope 下载接口。

仓库 [README](../README.md) 说明 Live2D 模型素材来自 BangDream 游戏数据包；ModelScope 地址是**应用配置的下载托管地址**，不等同于素材的原始版权来源。
