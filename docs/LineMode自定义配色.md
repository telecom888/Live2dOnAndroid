# Line Mode 自定义配色

在“设置 → 个性化 → Line 模式外观”中，可以分别修改我方消息框、对方消息框、聊天背景的颜色。输入格式为 `#RRGGBB`。默认颜色与原界面一致：

| 部位 | 默认颜色 |
| --- | --- |
| 我方消息框 | `#FFE327` |
| 对方消息框 | `#FFFFFF` |
| 聊天背景 | `#AAC2D3` |

也可以选择聊天背景图片。图片只铺在消息区域，工具栏和输入区仍使用选定的背景颜色。图片优先于消息区域的背景颜色；点击“使用颜色”可以移除图片并恢复颜色背景。选择的图片会复制到应用私有目录，避免相册临时授权失效。最多支持 20 MB 的可解码图片。

以上外观仅在 Line Mode 生效，同时用于完整会话页和 Live2D 悬浮聊天面板。“恢复默认配色”会恢复上述三种颜色并移除自定义图片。气泡文字会根据自定义颜色自动选用深色或浅色，以保持可读性。
