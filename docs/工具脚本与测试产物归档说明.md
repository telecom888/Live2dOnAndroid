# 工具脚本与测试产物归档说明

> 适用仓库：Live2dOnAndroid。范围：`tools/` 目录、仓库根目录散落的测试日志。目的：给每个文件夹/文件组做标注，测试中间文件统一归档，便于后续维护与清理。

## 1. 原则与目录总览

1. **保留**：可复用的语音生成/核验/分析脚本（`tools/` 根目录 `*.py`、`*.mjs`）与克隆参考样本（`tools/clone_samples/`）。
2. **归档**：测试过程产生的日志、报告、候选/评审音频、参数测试输出等，统一移入 `tools/archive/`，按类别分目录。
3. **不入库**：agent 一次性开发/补丁脚本 `tools/_*.py`、`*.log/*.err`、未跟踪的 `*.wav`（gitignore 已覆盖）；归档目录里的这类文件以 `[local]` 标记，仅本机留存。

```
tools/
├─ clone_samples/        # 保留：各角色克隆参考样本（sample1-3 + combined + manifest.json）
├─ <35 个可复用脚本>.py  # 保留：语音生成/重生成/核验/分析工具（见 §2）
├─ mimo_audio_verify.mjs # 保留：mimo 音频接口核验脚本
├─ _*.py                 # 不入库：一次性补丁/探针脚本（agent 开发用）
└─ archive/              # ★ 测试中间文件统一归档
   ├─ 01_logs/           #   运行日志 / 错误输出（*.log / *.err）
   ├─ 02_reports/        #   扫描 / QA / 核验报告（*.txt / *.json）
   ├─ 03_gen_tmp/        #   批量生成候选音频与角色立绘
   ├─ 04_param_test/     #   本地 TTS 参数对照测试音频
   ├─ 05_review_audio/   #   人工评审试听音频（5 批）
   ├─ 06_snapshots/      #   旧代码整文件快照
   └─ MANIFEST.md        #   逐文件清单（自动生成）
```

## 2. tools/ 根目录（保留内容）标注

### 2.1 语音生成 / 重生成脚本

| 文件 | 说明 |
|---|---|
| `generate_builtin_voices.py` | 内置语音（中文/日语）批量生成入口 |
| `generate_plain_batch.py` | 无填充文本的对照批量生成 |
| `generate_padded.py` | 短句填充文本后再生成（rana 等时长过短场景） |
| `generate_rana_candidates.py` / `generate_rana_retry.py` | rana 台词候选与重试生成 |
| `generate_voices_fix.py` / `generate_voices_local.py` | 问题音频修复 / 本地 Qwen3-TTS 批量生成 |
| `regenerate_asr.py` / `regenerate_final.py` / `regenerate_flagged.py` / `regenerate_plain2.py` / `regenerate_special.py` | 各类重生成批次（ASR 校正、终版、问题项、无填充、特殊项） |

### 2.2 核验 / 复核 / 分析脚本

| 文件 | 说明 |
|---|---|
| `verify_voices_mimo.py` | mimo-v2.5 全量语音核验（并发） |
| `verify_voices_mimo_qa.py` | mimo 核验 QA 报告生成 |
| `mimo_audio_verify.mjs` | mimo 音频输入接口格式探测/核验（JS） |
| `local_qwen_review.py` ~ `local_qwen_review4.py` | 本地 Qwen3-TTS 结果试听复核（1-4 版） |
| `recheck_fixed.py` / `recheck_rana.py` / `recheck_retry.py` / `recheck_short.py` | 复核批次（修复项 / rana / 重试 / 短音频） |
| `analyze_flagged.py` / `analyze_onset.py` | 问题音频标记分析 / 起音（首音缺失）特征分析 |

### 2.3 裁边 / 毛刺 / 参数实验脚本

| 文件 | 说明 |
|---|---|
| `cut_trailing_filler.py` / `fix_trailing_filler.py` / `fix_trailing_filler2.py` | 结尾填充符（えっど 等）统一切分/修复 |
| `padding_analyze.py` / `padding_test.py` | 填充文本效果分析 / 测试 |
| `probe_noise.py` / `probe_start.py` | 音频开头毛刺/杂音探测 |
| `qwen_param_test.py` / `plain_test.py` | Qwen 参数对照 / 无填充对照测试 |
| `build_voice_samples.py` | 构建克隆参考样本（sample → combined） |
| `local_taki_alt.py` | 立希（taki）本地备选音色生成 |

### 2.4 clone_samples/ 克隆参考样本（保留）

- 每角色 3 个 `sampleN.mp3` + `combined.mp3`，`manifest.json` 记录来源/用途。
- 用途：作为 mimo 音色克隆/本地 TTS 的参考音源，与人工试听对比用，**不是测试中间产物**，故不归档。

### 2.5 不入库开发脚本 `tools/_*.py`

- 形如 `_patch_*.py`（补丁）、`_probe_*.py`（探针）、`_write_*.py`/`_fix_*.py`/`_rename_*.py` 等，为开发过程一次性脚本，gitignore 忽略，不入库。
- 说明：若清理，直接删除即可；归档整理脚本本身也以 `_` 前缀命名，同属此类。

## 3. tools/archive/ 归档目录标注

### 3.1 `01_logs/` — 运行日志 / 错误输出（37 个，均为 [local]）
- 来源：仓库根目录 + `tools/` 根目录散落的 `*.log` / `*.err`。
- 组：`generate_*`（批量生成日志）、`regenerate_*`（重生成）、`verify_all*`/`verify_final`/`verify_run_console`（核验运行）、`padding_analyze`/`plain_test`/`plain_tomori`（实验）、`_fix3`/`fix_filler`（修复运行）。
- `.err` 为对应命令的错误输出（stderr），`.log` 为 stdout。

### 3.2 `02_reports/` — 扫描 / QA / 核验报告（16 个）

| 文件 | 说明 |
|---|---|
| `bandname_scan.txt` | 乐队名文案扫描结果（当时为空） |
| `flagged_analysis.txt` | 问题音频标记分析（文本） |
| `latin_scan.txt` | 台词拉丁/罗马字扫描 |
| `qa_smoke.txt` | QA 冒烟输出 |
| `recheck_fixed.txt` / `recheck_rana.txt` / `recheck_rana2.txt` / `recheck_rana3.txt` / `recheck_retry.txt` / `recheck_short.txt` | 各复核批次文本报告 |
| `verify_qa_report.txt` / `verify_qa_report.json` | mimo QA 核验报告（文本 + JSON） |
| `verify_report.txt` / `verify_report.json` | 全量语音核验报告（文本 + JSON） |
| `onset_analysis.json` | 音频起音/首音缺失特征分析 |
| `regen_targets.json` | 待重生成目标清单 |

### 3.3 `03_gen_tmp/` — 批量生成候选音频与立绘（282 个）
- 根目录：`<角色>_<序号>.wav/.mp3`（anon/soyo/rana/tomori/taki 批量生成候选）。
- `cands/`：重试候选音频（rana 等）。
- `plain/`：无填充版对照音频。
- `portraits/`：角色立绘；`portraits/bestdori/` 为从 Bestdori 下载的官方立绘，`portraits/body/` 为半身/全身裁切结果。
- 已跟踪的 `.wav/.mp3` 随本归档被 `git mv`（重命名）；未跟踪的 `*.wav` 按 gitignore 保持 [local]。

### 3.4 `04_param_test/` — 本地 TTS 参数对照测试（17 个）
- 用途：排查本地 Qwen3-TTS 输出开头毛刺/杂音（见需求历史）。
- `A_current.mp3/.wav`、`B_minp_fix`、`C_offline`、`D_lowsub`：4 组参数组合试听。
- `trimmed/`、`trimmed_adaptive/`：开头裁剪 / 自适应去首音实验输出。

### 3.5 `05_review_audio/` — 人工评审试听音频（120 个，5 批）
- `review_audio/`：首批 mimo 生成试听。
- `review_audio_local/` ~ `review_audio_local4/`：本地 Qwen3-TTS 试听批次 1-4。
- 文件模式：`<角色>_<序号>.mp3/.wav`；本地批含 `_raw.wav`（未处理）与 `_ref.wav`（参考音）。

### 3.6 `06_snapshots/` — 旧代码快照（1 个）
- `_old_service.kt`：改造前的 `Live2DWallpaperService` 整文件快照，用于对比/回溯。

## 4. 仓库根目录清扫

根目录原散落的 `verify_all*.log/.err`、`regen_*.log/.err`、`regenerate_*.log/.err`、`regen_asr`、`fix_filler`、`_fix3` 等 37 个运行日志/错误输出，已全部移入 `tools/archive/01_logs/`。仓库根目录不再保留测试运行日志。

## 5. 后续约定

1. 语音生成/核验脚本输出请写到 `tools/archive/` 下的新子目录或系统临时目录，不要再散落到仓库根与 `tools/` 根。
2. 每次新归档请同步更新本文件对应小节；`tools/archive/MANIFEST.md` 可由 `tools/_archive_gen_docs.py` 重新生成。
