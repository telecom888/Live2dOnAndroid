# 单段回复续写

在「设置 → 个性化 → 消息显示」中开启「继续生成按钮」（默认开启）。本功能只适用于单段回复。

- 网络异常、流提前结束、输出长度达到上限或手动停止后，保存已收到的正文。
- 只有当前分支最后一条消息是未完成的单段回复时才提供「继续生成」。不显示额外中断标签。
- 用户发送新消息后，原回复的按钮隐藏；新回复若再次中断，可继续新回复。
- 点击后携带系统提示和当前分支完整上下文，以新请求续写。生成中和保存后都追加到同一条气泡。
- 续写再次中断仍能继续；中断状态和内部请求顺序随聊天记录保存，重新打开聊天后可用。
- 未收到正文的网络失败保留原有重试行为；多段回复不提供续写按钮。

为保留请求前缀，续写后的显示正文与内部请求历史分开保存。界面显示一条合并回复；内部保留 assistant 部分正文、user 续写指令、assistant 后文的顺序。后续请求复用这个顺序，不显示额外 user 气泡。缓存能否命中仍由服务商决定。

这项功能会发起新的模型生成，无法恢复被取消请求的模型内部状态，也无法保证模型不重复前文。

## 验证

本地 HTTP 测试覆盖三种协议的异常 EOF、输出上限、手动取消；历史测试覆盖续写重复中断、保存重载、完整请求上下文和追加新消息。

本次已通过卷桥使用 `gemini-3.1-flash-lite` 验证两种中断后的续写成功；测试密钥已删除，临时 API 测试脚本已清理。未进行真机交互验证。
